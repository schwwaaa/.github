**schwwaaa** is an independent applied research, software, and creative technology studio building tools for media, graphics, broadcast, automation, and human-computer interaction.

We build **creative instruments, local-first utilities, media infrastructure, GPU systems, and experimental software** — often where existing tools stop being useful.

## Work

- **Creative systems** — real-time video, feedback, glitch, generative graphics, and artist tools
- **Media infrastructure** — archival workflows, broadcast utilities, OBS control, routing, recording, and analysis
- **GPU + graphics** — Rust, `wgpu`, WebGL, GLSL, native rendering, and high-resolution media systems
- **Applied research** — AI-assisted workflows, HCI, automation, prototyping, and unconventional interfaces

## Selected projects

- [**AdSlicer**](https://github.com/schwwaaa/AdSlicer) — local-first analysis and slicing for VHS and broadcast recordings
- [**HUFF**](https://github.com/schwwaaa/huff) — real-time feedback and video corruption instrument
- [**Junkpile**](https://github.com/schwwaaa/junkpile) — creative coding and native GPU media experiments
- [**videobeaux**](https://github.com/schwwaaa/videobeaux) — video tools built for artists
- [**obs-relay**](https://github.com/schwwaaa/obs-relay) — remote OBS control and API tooling
- [**mastacraf**](https://github.com/schwwaaa/mastacraf) — local Rust + FFmpeg audio mastering pipeline

Projects range from finished tools to active research, prototypes, infrastructure, and archives. See each repository for its current status and documentation.
